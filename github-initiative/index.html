Girl students who are interested in learning GitHub and improving their technical skills.

No. The initiative is beginner-friendly.

Free to participate. There is no registration fee.

What will I learn?
  • Git & GitHub basics
  • Repositories
  • Branching
  • Commits
  • Pull requests
  • Collaboration
  • Best practices

Yes. A Certificate of Participation/Completion will be awarded to students who successfully complete the initiative and actively participate in the sessions.

Yes. Participants will complete hands-on exercises and GitHub activities throughout the initiative.

GitHub is an essential platform for software development. Learning GitHub helps you:

  • Prepare for internships and placements
