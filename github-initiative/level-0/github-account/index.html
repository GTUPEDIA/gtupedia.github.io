Module 1 · ~25 min

GitHub account & profile

Goal: Create a professional GitHub identity recruiters and teammates can recognize.

Steps

  1. Sign up at github.com/signup.
    • Use a username you are comfortable showing on your resume.
    • Choose the free plan and verify your email.
  2. Secure the account — Settings → Password and authentication → enable 2FA. Save backup codes.
  3. Complete your profile — avatar → Your profile → Edit profile: photo, one-line bio, college or city.
  4. Explore the dashboard — find the + menu, Notifications, and Settings.
Tip: Your username becomes https://<username>.github.io. Pick something resume-friendly.

Checklist

  • GitHub account created and email verified
  • 2FA enabled
  • Profile photo and bio added
  • I can find Settings, Notifications, and the + menu
